# `src/lib/`

Server/shared TypeScript — **no React components**.

| Folder | Responsibility |
|--------|----------------|
| `auth/` | Sessions, passwords, TOTP |
| `cms/` | Portfolio content + project meta |
| `contact/` | Contact messages |
| `database/` | Supabase clients, CRUD, local media, migrations |
| `ai/` | AI settings + chat DB |
| `security/` | Captcha, rate limit, body limits |
| `platform/` | Env + app settings |
| `email/` | Resend |
| `integrations/` | Telegram |
| `seo/` | noindex helpers |
| `game/` | 2048 logic |
| `core/` | `cn` and shared utils |
